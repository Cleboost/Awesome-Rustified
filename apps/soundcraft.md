## Summary

SoundCraft is a clean-room DAW in pure Rust: multitrack audio, inserts and sends, MIDI instruments, automation (Write/Touch/Latch), markers, and Pro Tools–like mix and edit windows.

## Stack

- [craft-libs](https://github.com/storytold/craft-libs)
- Built-in synths, SMF import/export (per upstream docs)

## Why Rust

Low-latency audio paths and a complex UI without relying on a web runtime for the desktop product.
