## Summary

EffectCraft is a compositor in the After Effects spirit: compositions, layers, keyframes, a large effect set, layer styles, expressions, 3D cameras and lights, and a render queue — already usable while still evolving quickly.

## Stack

- [craft-libs](https://github.com/storytold/craft-libs)
- Web preview via `effectcraft-web`

## Why Rust

Effect graph, rendering, and UI live in one Rust workspace instead of a scriptable Electron host.
