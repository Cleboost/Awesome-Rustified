## Summary

VectorCraft is a fast, clean-room vector editor: paths, blends, live effects, and Illustrator-like document workflows, implemented in pure Rust.

## Stack

- [craft-libs](https://github.com/storytold/craft-libs)

## Why Rust

Vector geometry, rendering, and file IO stay in Rust for predictable performance on large illustrations.
